# カスタムクルーメイト 
判定 : ノーマル  
＜#属性＞

ホストが設定した属性を持つクルーメイト。

# パン屋 
判定 : ノーマル  
＜#会議 #陣営変化＞

自身が生存している間、会議が始まる度にパンを振る舞い、自動でメッセージを流す。

設定確率により第三陣営に覚醒し、会議が始まる度に毒入りパンをランダムの船員1人に提供する。覚醒パン屋を追放しなければ、会議終了時に渡された船員は毒死する。  
インポスターまたはクルーの人数による勝利条件達成時、覚醒パン屋が生存していると乗っ取って単独勝利する。

# ハンター 
判定 : インポスター  
＜#キル可能 #キル能力＞

相手をキルできる。タスクなし。

(キルした時、相手の陣営がわかる)がオンの時、キルした相手の陣営を探知し、自身の名前の横にマークが表示される。
